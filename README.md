# БАМБОЛБИ

Локальная панель управления цифровыми билбордами. Реестр экранов, кампании, медиатека, недельное расписание, виртуальный плеер, отчёты, журнал изменений и доска проекта работают с одной базой SQLite.

## Локальный запуск

Понадобятся **Node.js 24 или новее** и **Python 3.10 или новее**. Для загрузки видео установите FFmpeg и убедитесь, что команда `ffprobe -version` доступна в терминале. Для изображений FFmpeg не нужен. На Windows можно запустить `start.cmd`. При первом запуске он создаст окружение Python и установит зависимости. Для этого шага нужен доступ к PyPI.

Ручной запуск на Windows из PowerShell:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

На macOS или Linux:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

Откройте **[http://127.0.0.1:5050](http://127.0.0.1:5050)**. Остановите сервер сочетанием **Ctrl+C** в его терминале. Flask слушает только интерфейс loopback и запускает API Node.js на внутреннем случайном порте. Локальная панель работает под демонстрационной учётной записью администратора. Интернет после установки нужен только для внешней карты.

Интерфейс React уже собран. После изменений в `ui/` пересоберите его:

```sh
npm ci
npm run build
```

## Демонстрация

1. При первом запуске создаются шесть экранов, четыре кампании, четыре рекламных изображения, несколько слотов, история показов, задачи и риски. Начальные слоты помечены относительно времени первого запуска. Чтобы показать уже назначенную рекламу, откройте плеер с главной страницы.
2. Добавьте новый билборд со статусом «В сети» и создайте активную кампанию. Загрузите изображение в медиатеку и нажмите «Согласовать».
3. Создайте слот для нового экрана, указав текущую минуту Москвы началом, более позднее окончание и цикл 3–120 секунд. Попробуйте сохранить второй слот с пересечением на том же экране.
4. Откройте плеер для этого билборда и дождитесь завершения полного цикла. Если плеер открыт посреди текущего цикла, учёт начинается со следующей границы цикла. Повтор события для того же цикла не увеличивает счётчик.
5. В отчётах найдите показ по экрану или названию кампании. CSV содержит весь отфильтрованный журнал. Для PDF нажмите «Печать / PDF» и выберите в браузере «Сохранить как PDF».
6. Поставьте кампанию на паузу. Плеер перейдёт в режим ожидания после очередного запроса плейлиста. В разделе «Проект» добавьте задачу, измените её статус и заполните карточку риска.

SQLite и загруженные файлы хранятся в `runtime/`. Они сохраняются при перезапуске. Для резервной копии остановите приложение и скопируйте каталог целиком. Чтобы начать демонстрацию заново, остановите сервер и переименуйте `runtime/`. При следующем запуске будет создана новая база с демоданными. Переменная `BAMBOLBI_DATA` позволяет указать другое место хранения.

## Развёртывание с Docker Compose

1. Направьте DNS домена на сервер и обеспечьте доступ к портам 80 и 443.
2. Создайте хеш пароля командой `docker run --rm -it caddy:2 caddy hash-password`. Введите пароль по запросу.
3. Создайте рядом с `compose.yaml` файл `.env` со своим доменом, логином и хешем. Используйте одинарные кавычки вокруг хеша, чтобы Compose не интерпретировал символы доллара.

```dotenv
SITE_DOMAIN=ads.example.org
ADMIN_USER=admin
ADMIN_HASH='<хеш, полученный от Caddy>'
```

4. Выполните `docker compose up -d --build`. Откройте сайт по HTTPS и войдите под настроенной учётной записью. Caddy получает сертификат, требует логин и пароль и передаёт имя администратора для журнала изменений. Порт приложения доступен внутри сети Compose, данные хранятся в томе `app_data`.

## Состав

- `ui/` и `static/` — исходники React, готовая сборка, стили и демонстрационные объявления.
- `app.py` — локальный запуск Flask и проксирование запросов к API.
- `server.mjs` и `demo.mjs` — API Node.js, схема SQLite, расписание, учёт показов и демонстрационные данные.
- `validate_media.py` — проверка содержимого изображений и видеоконтейнеров.
- `Dockerfile`, `compose.yaml` и `Caddyfile` — конфигурация самостоятельного развёртывания.
